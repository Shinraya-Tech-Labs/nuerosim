# T033 — Izhikevich regular spiking

The production workbench provides a regular-spiking Izhikevich variant with configurable `izh_a/b/c/d`, reset, recovery state, and current drive. Units are mV, ms, and µA/cm². A deterministic 50 µA/cm² pulse produces repeated spikes; this is an implementation audit, not a universal biological classification.

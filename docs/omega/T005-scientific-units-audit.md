# Scientific units audit

Run the audit on a workbench result JSON file:

```sh
PYTHONPATH=python python -m neurosim.units_audit results.json
```

For a ZIP export, extract its `results.json` member first. The report checks that declared manifest units match the workbench contract, that each spike train belongs to a configured neuron, that spike times lie within the duration in milliseconds, and that the stored mean rate matches `spike_count / neurons / (duration_ms / 1000)` in Hz. Rate comparisons allow only `rel_tol=1e-12` and `abs_tol=1e-12` for floating-point rounding.

Malformed data, mismatched units, invalid durations/counts, non-finite or out-of-range spike times, and inconsistent rates exit nonzero with an explanatory error. The audit does not infer missing units, convert values, check every parameter, validate model equations, or establish biological accuracy. No scientific claim beyond these data consistency checks is made.

## Verification checklist

- [x] Recompute the fixture rate: 2 spikes / 1 neuron / 1 second = 2 Hz.
- [x] Audit a result generated by the workbench engine.
- [x] Reject incorrect units and invalid rate inputs.
- [x] Check duration and spike-time boundaries.
